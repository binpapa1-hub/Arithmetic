# QA 체크리스트 및 실행 가이드

## QA 개요

본 문서는 계산기 프로젝트의 품질 보증(Quality Assurance)을 위한 체크리스트와 실행 절차를 제공합니다.

## 1. 자동화된 테스트 실행

### 1.1 단위 테스트 실행

```bash
# 모든 테스트 실행
pytest tests/ -v

# 특정 테스트 파일 실행
pytest tests/test_arithmetic.py -v
pytest tests/test_calculator_service.py -v

# 커버리지 포함 실행
pytest --cov=src --cov-report=term-missing tests/
```

**체크리스트:**
- [ ] 모든 테스트 통과 (18개)
- [ ] 코드 커버리지 100% 이상
- [ ] 테스트 실행 시간 < 1초

### 1.2 테스트 커버리지 확인

```bash
pytest --cov=src --cov-report=html tests/
```

**체크리스트:**
- [ ] `src/arithmetic.py` 커버리지 100%
- [ ] `src/calculator_service.py` 커버리지 100%

## 11. QA 실행 스크립트

### quick_qa.sh (Linux/macOS)

```bash
#!/bin/bash
echo "=== QA 실행 시작 ==="

echo "1. 단위 테스트 실행..."
pytest tests/ -v

echo "2. 코드 커버리지 확인..."
pytest --cov=src --cov-report=term-missing tests/

echo "3. 코드 품질 검사..."
pylint src/ --score=y
flake8 src/ --max-line-length=100

echo "=== QA 완료 ==="
```

### quick_qa.bat (Windows)

```batch
@echo off
echo === QA 실행 시작 ===

echo 1. 단위 테스트 실행...
pytest tests/ -v

echo 2. 코드 커버리지 확인...
pytest --cov=src --cov-report=term-missing tests/

echo 3. 코드 품질 검사...
pylint src/ --score=y
flake8 src/ --max-line-length=100

echo === QA 완료 ===
pause
```
